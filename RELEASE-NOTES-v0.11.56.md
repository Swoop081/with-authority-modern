# WWE Legacy CCG v0.11.56 — Starting HP Rebalance

- Rebalanced starting HP across all 29 currently playable Superstars so durability is a meaningful roster attribute instead of a near-universal 50.
- Final Boss Rock remains the prestige ceiling at 58 HP.
- True giants/heavyweights such as André, Brock, Oba, Kane and Undertaker now carry higher starting durability.
- Smaller/high-speed wrestlers such as IYO SKY, Liv Morgan, Logan Paul and Sol Ruca sit at the lower end of the HP band.
- HP was assigned using both wrestler archetype and the current multi-seed gameplay read; this is a durability pass, not a substitute for the later full-card balance pass.
- No card, deck, collector-number or artwork assignment changed.
