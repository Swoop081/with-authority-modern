# WWE.com menu Superstar photography

v0.12.48 uses a deliberately fixed **12-Superstar dedicated menu-render cast** sourced from official WWE Superstar profile pages. These images are used only for menu/presentation composition and are cached locally as optimized WebPs so GitHub Pages/iPhone rendering does not depend on live WWE.com requests. Collectible-card artwork remains separate and unchanged.

The dedicated cast is exactly four SummerSlam Series 1 Superstars, four Hall of Fame Series 1 Superstars and four Evolution Series 1 Superstars:
