# WWE Legacy Move card front templates

These SVG files mirror Move Card Studio v0.11.18. They are optional editable references for external graphics work.

Front hierarchy is intentionally fixed:

1. Full-bleed set background
2. User-supplied Move artwork (replace the `MOVE_ART` placeholder)
3. Small set logo at top-right
4. Move name at bottom
5. Compact `COST` and `DAM` line below the name
6. Set-colour outer frame

No method, Move Type, requirements, counters, rarity, Superstar restriction, Finisher/Trademark/Signature label, effects text or foil label belongs on the front. Those details are shown on WWE Legacy's shared rules back.
