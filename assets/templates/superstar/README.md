# WWE Legacy Superstar full-art templates

These four 680 × 1000 SVGs are full-bleed background/frame source templates for Superstar collectible fronts.

- `summerslam-series-1.svg`
- `hall-of-fame-series-1.svg`
- `evolution-series-1.svg`
- `rewards.svg`

The set background must cover the complete 680 × 1000 card, including the area behind the Superstar name at the bottom. There is no separate black lower panel.

The intended finished composition is: **full-bleed set background + wrestler artwork + small set logo (top-right, where applicable) + Superstar name at the bottom**. Do not add Superstar, Foil, HP, rarity stars, card type or gameplay statistics to the front.

Open `tools/superstar-card-studio.html` to load/reposition wrestler artwork and export the finished WebP.
