# WWE Legacy Superstar full-art templates

These four 680 × 1000 SVGs are background/frame source templates for Superstar collectible fronts.

- `summerslam-series-1.svg`
- `hall-of-fame-series-1.svg`
- `evolution-series-1.svg`
- `rewards.svg`

The intended finished composition is: **set background + wrestler artwork + wrestler's real-life logo**. Do not add Superstar, Foil, HP, rarity stars, card type or gameplay statistics to the front.

For the easiest workflow, open `tools/superstar-card-studio.html` in the project. It reproduces these four identities, lets you load the wrestler image and logo, and exports a finished WebP at the standard 680 × 1000 game size.
