# Golden Era — Series 1 branding

The set mark uses the classic WWF block logo geometry from Wikimedia Commons: `World Wrestling Federation block logo.svg` (1982-era mark; Commons notes a variation was used 1982–1997). The local `golden-era-wwf-logo.svg` recolours that geometry into the WWE Legacy Golden Era red/gold/cream palette and adds a Golden Era set label.

Source: https://commons.wikimedia.org/wiki/File:World_Wrestling_Federation_block_logo.svg
