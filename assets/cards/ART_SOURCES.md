# Temporary artwork sources — v0.5.2

These files are temporary visual stand-ins so every collectible card has an image while final card-specific photography is sourced.

The game always prefers an exact entry in `js/data/card-art-overrides.js`. Adding a final image for a card replaces the temporary fallback everywhere without touching gameplay data or templates.
