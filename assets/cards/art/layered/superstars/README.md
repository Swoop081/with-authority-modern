# Layered Superstar fronts

Card Art Studio exports Superstar Layered v1 fronts here using the canonical
Superstar ID as the filename.

Examples:
- `roxanne-perez.webp`
- `logan-paul.webp`
- `raquel-rodriguez.webp`
- `sol-ruca.webp`
- `bret-hart.webp`
- `diesel.webp`

Do not prefix these files with `superstar-`. The live resolver uses the same
filename convention as Card Art Studio and attempts these fronts automatically.
