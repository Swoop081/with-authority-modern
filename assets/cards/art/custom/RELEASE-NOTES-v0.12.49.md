# WWE Legacy: Collectible Card Game — v0.12.49
## Physical Booster Pack Pass

v0.12.49 supersedes v0.12.48 as the current working baseline.

This is a presentation-only booster-product pass. No gameplay, roster, AI, card values, pack odds, economy, submission, pin, Counter, Momentum, Entrance or Adrenaline rules changed.

### Physical wrapper system

- Replaces the old rounded card-like booster silhouette with one reusable sealed foil-wrapper component.
- Adds heat-crimped top and bottom seals, vertical side seams, a tear notch, foil ridging, wrapper highlights and subtle reflective sweep.
- Uses a taller/narrower physical pack proportion instead of collectible-card proportions.
- Set branding is printed into the wrapper face with a clearer logo → set → series → contents hierarchy.
- SummerSlam, Hall of Fame, Evolution, Survivor Series and Rewards packs inherit distinct wrapper material/accent families while sharing the same physical construction.

### One pack language everywhere

The same physical booster component is now used by:
- Booster Vault products
- Card Shop featured booster
- Season/tier booster rewards
- Match booster rewards
- Full-screen sealed-pack opening
- Pack-rip animation

### Opening presentation

- The sealed pack floats as a physical foil wrapper.
- The opening animation now tears the crimped top seal rather than removing a generic rectangular cap.
- Existing card reveal, rarity, foil and summary flows are unchanged.
