# Finished Superstar card fronts

Place the WebP files exported by **Superstar Art Studio** in this folder.

The filename must match the Superstar id shown by the studio, for example:

- `cody-rhodes.webp`
- `cm-punk.webp`
- `roman-reigns.webp`
- `hulk-hogan.webp`
- `rhea-ripley.webp`
- `the-rock.webp`

WWE Legacy v0.11.16+ automatically checks this folder first for every Superstar-facing visual in the game. No JavaScript manifest edit is required. If a finished card file is not present, the game falls back to the older portrait art so nothing breaks.

The same finished card front is used for Superstar cards in Collection/boosters and for Superstar imagery on splash, onboarding, menus, Season/booster/Collection heroes, roster selection, profile, ladders and the match HUD.
