# Superstar HUD headshots

Card Art Studio Headshot exports belong here using the canonical Superstar ID.
The match HUD now resolves this path for every roster member automatically.

Examples:
- `roxanne-perez.webp`
- `logan-paul.webp`
- `raquel-rodriguez.webp`
- `sol-ruca.webp`
- `bret-hart.webp`
- `diesel.webp`
