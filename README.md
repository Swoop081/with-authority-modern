# WWE Legacy: Collectible Card Game — v0.11.83

Current canonical development baseline: **v0.11.83 — Pin Probability Overhaul + Final Season 1 Simulation Balance Pass**.

This build overhauls pin probability so Amber-health covers are extremely unlikely and Red health is the true finishing phase, then runs a final 3,280-match Season 1 simulation pass with targeted roster and AI corrections.

Season 1 contains **41 playable Superstars** across SummerSlam, Hall of Fame, Evolution, RAW, Worlds Collide, Money in the Bank, SmackDown and the Season 1 Final Boss reward package.

Run `npm test`, `npm run validate`, `npm run card-ids`, and `npm run flow` for release validation. The art audit intentionally reports missing final artwork while placeholder production is in progress.
