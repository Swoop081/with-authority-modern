# WWE Legacy: Collectible Card Game

Current working build: **v0.13.2 — Once Too Often**.

A mobile-first WWE collectible card game prototype with 60-page Superstar decks, Method Momentum, Adrenaline, Counters, Submissions, Pins, Deck Lab, Collection, boosters, Store, Seasons, Challenges, Live Event towers, Ladder and Championship Road.

## Current build
- Adds the universal reactive Action **SS1-145 Once Too Often**.
- Every authored deck starts with 1 copy; players may collect and run up to 5.
- Repeated exact-card Moves can be reversed by Once Too Often, including repeated Finishers.
- Existing complete saved decks migrate safely to one copy outside Lead Off 5.
- Layered Card Front v1 from v0.13.1 remains opt-in and existing flat fronts remain untouched.

See `RELEASE-NOTES-v0.13.2.md` and `BUILD-CERTIFICATION.md`.
