# WWE Legacy v0.13.81 — New Generation British Bulldog Completion Pass

Mobile-first WWE Legacy prototype for iPhone Safari / Chrome.

This build authors **British Bulldog** as the eighth and final planned New Generation — Series 1 Superstar and completes the set at **NG1-080**.

## Highlights
- New Generation — Series 1 is now fully authored with Bret Hart, Shawn Michaels, Razor Ramon, Diesel, Doink the Clown, Yokozuna, Owen Hart and British Bulldog.
- 6 new shared New Generation low-rarity cards at **NG1-068–073**.
- British Bulldog's complete 7-card collector package at **NG1-074–080**.
- British Bulldog uses a 60-page Strength/Technical hybrid deck with **Power & Technique** and **Made in Britain**.
- **Bulldog’s Running Powerslam** is a C10/D17 Very Rare Finisher, keeping 17 Damage at the top of the normal Finisher tier.
- **Made in Britain** searches one low-rarity Strength Move and one low-rarity Technical Move.
- Card Art Studio and Superstar nameplate data are regenerated for the completed roster.
- Existing NG1-001–067 collector identities remain unchanged.
- New Generation remains scheduled for **5 September 2026**.
