# WWE Legacy: Collectible Card Game — v0.11.61

Internal Season 1 development build containing the current 33-Superstar pool through **Worlds Collide — Series 1**.

This build adds the cinematic Exhibition matchup/Entrance flow, redesigned in-match HUD and the corrected one-Momentum-per-Control-sequence rule. All existing collector IDs, decks and Card Art Studio assignments remain preserved.

Run `npm test`, `npm run validate`, `npm run card-ids`, `npm run flow`, `npm run economy`, `npm run art`, and `npm run balance` for release validation.
