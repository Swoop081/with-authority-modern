# WWE Legacy: Collectible Card Game

Current working build: **v0.12.75 — Booster Collation Hotfix**.

v0.12.75 builds on v0.12.74 and tightens five-card booster collation after the exclusive-rarity pass:

- A booster may contain **no more than one Very Rare (4★)** card total.
- Superstar chase cards count toward that one-4★ ceiling.
- Very Rare Finishers, Specials and Entrances therefore cannot stack into multi-Very-Rare jackpot packs.
- Base rarity weights remain **50/30/15/5** until a Very Rare is pulled; later slots then exclude 4★ cards.
- The first-slot Foil guarantee, Entrance Foil handling, Superstar chase/pity, duplicate handling and Universe Points remain unchanged.
- All v0.12.74 exclusive-rarity policy, v0.12.73 Deck Lab inspection behavior and earlier gameplay/presentation rules remain in force.

See `RELEASE-NOTES-v0.12.75.md` and `BUILD-CERTIFICATION.md`.
