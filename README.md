# WWE Legacy: Collectible Card Game

Current working build: **v0.13.65 — Shared Move Triple Pass**.

A mobile-first WWE collectible card game prototype with 60-page Superstar decks, Method Momentum, Adrenaline, Counters, Submissions, Pins, Deck Lab, Collection, boosters, Store, Seasons, Challenges, Live Events, Money in the Bank, King of the Ring and Championship Road.

## Current build
- Adds **Vertical Boston Crab — EVO1-075**, shared **2★ Uncommon**: **C6 / D0 / Technical 2 / Submission / Rear Control**, grounded opponent only, **+4 persistent Back damage per successful turn**.
- Adds **Diving Shoulder Block — HOF1-094**, shared **1★ Common**: **C4 / D6 / Agility 1 / Aerial / Diving Aerial**, grounds opponent. It is a separate generic card from Ultimate Warrior’s existing exclusive Diving Shoulder Block.
- Adds **Springboard Roundhouse Kick — SD1-038**, shared **3★ Rare**: **C6 / D9 / Agility 2 + Strike 1 / Aerial / Running Aerial**, grounds opponent.
- All three are booster-only shared moves and are not installed in authored Superstar decks in this pass.
- Card Studio exposes all three under their assigned collector sets.
- Evolution is now **75 cards**, Hall of Fame **94 cards**, and SmackDown **38 cards**, each gap-free.
- SmackDown retains its existing future-set release gating.
- All v0.13.64 and earlier accepted gameplay, mobile UX, Championship Road, Lead Off/shuffle integrity, Foil systems and set identities remain intact.
