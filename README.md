# WWE Legacy: Collectible Card Game

Current working build: **v0.13.34 — Victory + Super Pack Economy Pass**.

A mobile-first WWE collectible card game prototype with 60-page Superstar decks, Method Momentum, Adrenaline, Counters, Submissions, Pins, Deck Lab, Collection, boosters, Store, Seasons, Challenges, Live Events, Money in the Bank, King of the Ring and Championship Road.

## Current build
- **Every match victory in every mode awards 1 normal booster.** A loss awards **no match reward** and **0 match Season XP**.
- Clearing a full structured mode/tournament awards an additional **Super Pack**: King of the Ring, Live Events, Money in the Bank and Championship Road all use the new mode-clear reward.
- **Super Packs** contain 5 cards, guarantee the first pull as **Foil Rare-or-better**, use boosted **25% Common / 40% Uncommon / 27% Rare / 8% Very Rare** weighting, and can contain up to **2 Very Rares**.
- King of the Ring retains its choose-one-of-three released-set reward presentation, but the chosen reward is now a **Super Pack**.
- Overflow duplicate conversion is reduced to **1 UP Common / 2 UP Uncommon / 3 UP Rare / 4 UP Very Rare**. Foil overflow pays the same rarity value.
- Existing Live Event win-UP bonuses remain additive to the new victory booster; this pass only reduces UP generated by overflow duplicates.
- Legacy unclaimed Money in the Bank / Championship special-pack credits migrate into the generic Super Pack wallet.
- Superstar chase remains **2% natural with one global 100-miss pity**.
- All v0.13.33 card, deck and collector changes remain locked with no card-balance changes in this pass.
- Profile schema advances to **31** for the Super Pack wallet/migration.

Season 1 release schedule remains: **RAW — Series 1 (5 Sep 2026)**, **Worlds Collide — Series 1 (26 Sep 2026)**, **Money in the Bank — Series 1 (10 Oct 2026)**, **SmackDown — Series 1 (31 Oct 2026)** and **Survivor Series — Series 1 (28 Nov 2026)**.
