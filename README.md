# WWE Legacy: Collectible Card Game

Current working build: **v0.12.33 — Retained-Control Draw + Roster Rebalance**.

v0.12.33 supersedes v0.12.32. A successful Move still retains Control and opens a fresh turn with one Momentum placement, but the retained-Control turn now draws **one page for the defender only**. The attacker does not automatically replace the Move just spent. Normal Control-transfer draws are unchanged, the connected-Move Adrenaline economy remains **attacker +1 / defender -1**, and Entrance Adrenaline still resolves once on first actual Control.

The roster has been rebalanced around this corrected hand-flow model. The rejected v0.12.30 comeback/rubber-band rules remain absent.

See `RELEASE-NOTES-v0.12.33.md`, `RETAINED-CONTROL-DRAW-AUDIT-v0.12.33.md`, `BALANCE-AUDIT-v0.12.33.md` and `DEEP-MATCH-STATS-v0.12.33.json`.
