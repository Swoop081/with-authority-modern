# WWE Legacy: Collectible Card Game — v0.11.52

Internal Season 1 development build containing the current 26-Superstar pool, including the first locked **Raw — Series 1** Superstar, Logan Paul.

Raw — Series 1 is scheduled for 5 September 2026. In this development build Logan is automatically unlocked for testing and artwork assignment; the future public release gate will hide unreleased content until its configured date.

Run `npm test`, `npm run validate`, `npm run card-ids`, `npm run flow`, `npm run economy`, `npm run art`, and `npm run balance` for release validation.
