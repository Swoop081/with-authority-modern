# WWE Legacy v0.13.30 — Kevin Owens Trademarks + MITB Shared Moves Pass

v0.13.30 adds the approved Kevin Owens identity expansion and three new shared moves while preserving the v0.13.29 iPhone presentation baseline and all established progression/economy rules.

## Kevin Owens
- **Avalanche Fisherman’s Buster** — 3★ Rare Kevin Owens-exclusive Trademark; C9 / D14 / Strength 3 / Body Elevated; grounds the opponent; costs 2 less if Kevin connected with a Strike earlier in the same Control sequence.
- **KO’s Swanton Bomb** — 3★ Rare Kevin Owens-exclusive Trademark; C7 / D11 / Agility 2 / Diving Aerial; grounded opponent only; deals +2 Damage if a Strength Move connected earlier in the same Control sequence.
- Kevin Owens’ authored 60-page recommended deck now contains 2 copies of each new Trademark, replacing generic Fisherman Buster, Frog Splash and one generic Senton slot while remaining exactly 60 pages / 12 Momentum.
- **Pop-Up Powerbomb remains Kevin Owens’ first/authored Trademark for the lean secondary-Superstar unlock**, so later KO unlocks still grant only one Trademark rather than automatically granting either new chase card.
- The existing generic Fisherman Buster remains collectible as a shared SummerSlam card even though it is no longer in an authored recommended deck.

## Money in the Bank — Series 1 shared additions
- **Trash Can to the Back** — 2★ Uncommon shared Weapon; C4 / D6 / Strike 1 / Arm Extended; on connect deals +1 persistent Back damage.
- **Chair to the Gut** — 2★ Uncommon shared Weapon; C4 / D5 / Strike 1 / Arm Extended; on connect the player’s next Grapple this Control sequence costs 1 less.
- **Splash** — 1★ Common shared Move; C3 / D5 / Strength 1 / Running Aerial; no additional effect.
- These three cards are authored into **Money in the Bank — Series 1** at MITB1-035 through MITB1-037 and remain hidden until that set’s release window.
