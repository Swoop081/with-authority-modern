# WWE Legacy v0.12.54 — Home Menu Hierarchy Pass

v0.12.54 supersedes v0.12.53 as the current working baseline.

This is a presentation/navigation-only update based directly on iPhone Home-screen review.

### Home / global shell
- Top-left gamebar brand now uses the WWE Legacy app icon instead of the small WWE LEGACY / CCG text lockup.
- `SEASON 1` is dramatically larger in the middle gamebar cell.
- Packs and Universe Points numbers are approximately three times their previous visual size.
- Enter the Ring CTA no longer includes the redundant `PLAY` label.
- Starter Superstar photography is enlarged to roughly twice the previous visual area on mobile.
- The Home Season strip uses and more prominently frames the dedicated Final Boss Rock presentation render.

### Full-width Home destinations
The old two-column command grid and utility rail are replaced with full-width rows in this order:
1. Deck Lab
2. Challenges
3. Open Packs
4. Store
5. My Collection
6. My Legacy

`Booster Vault` is now presented as `Open Packs`; `Card Shop` is now `Store`.

Challenge attention badges move to the upper-right so they no longer cover `EARN REWARDS`.

### Options removed
Options is removed from Home, the bottom nav, navigation routing and screen implementation. Existing reset/build tools remain in My Legacy.

### Gameplay
No gameplay, AI, roster, deck, card, pin, submission, counter, Momentum, Entrance, Adrenaline or economy rules changed.
