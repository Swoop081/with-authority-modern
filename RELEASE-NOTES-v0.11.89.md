# WWE Legacy v0.11.89 — Headshot Free-Pan Fix

- Fixed HUD Headshot artwork getting trapped at the old ±180 vertical / ±520 horizontal crop limits.
- Headshot artwork can now be dragged freely in the preview; slider ranges automatically remain large enough to reflect the active position.
- Expanded headshot zoom from 45–320% to 15–500% so unusually tall or padded transparent renders can be framed correctly.
- Preserved the existing tighter card-front positioning limits so normal collectible-card composition remains stable.
- Fixed Card Front and HUD Headshot crops so each export target truly keeps its own independent saved position when switching modes.
