# WWE Legacy v0.11.41 — My Collection Sort + Season Hub Polish

## My Collection
- Added a compact Sort dropdown without bringing the Catalogue Super Sort onto this screen.
- Sort choices: Newest Owned, A–Z, Z–A, Rarity High → Low, Rarity Low → High, and Most Copies.
- Newest Owned follows first appearance in the local owned-card inventory, so newly discovered cards rise to the top.

## Season 1 Hub
- Removed the Main Menu hero shortcut.
- Renamed Daily / Weekly to Challenges.
- Hero actions are now only Challenges and Boosters.
- Featured Release set logos moved to the left side of each tile so they do not overlap the three Superstar card images.

## Scope
- UI-only change. No gameplay, card pool, deck, balance, collector-number, booster, or Card Art Studio data changed.
- Build-wide cache busting stamped to v0.11.41.
