# WWE Legacy v0.11.25 — All-Sets Card Studio Search

- Card Art Studio now defaults the Set filter to **All Sets**.
- Search immediately scans all 389 active cards across SummerSlam, Hall of Fame, Evolution and Rewards.
- When All Sets is active, the Superstar filter lists all 25 Superstars.
- Choosing a specific set narrows both card results and the Superstar list to that set.
- No card, deck, collector-number, balance or artwork-path changes.
