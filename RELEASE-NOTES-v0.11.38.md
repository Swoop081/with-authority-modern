# WWE Legacy v0.11.38 — Compact Collection Header

## Collection / Card Catalogue
- Compresses the My Collection / Card Catalogue switch into a small segmented control.
- Converts set choices into one compact horizontal row that scrolls when needed instead of stacking into a large button grid.
- Condenses the four collection statistics into one four-column summary row.
- Shortens the collection hero and tightens its description/spacing so Owned Cards, search and the card grid appear much sooner.
- Keeps all existing Collection/Catalogue filters and destinations unchanged.
