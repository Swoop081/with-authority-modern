# WWE Legacy v0.12.71 — Bayley Signature Pass

## Bayley signature identity

- Added **Bayley’s Diving Elbow** as **EVO1-065**.
  - 3★ Rare
  - Cost 7 / Damage 12
  - Agility 2
  - Aerial / Diving Aerial counter state
  - Grounded opponent only
  - On Connect: draw 1 page
  - Bayley-exclusive
- Added **Bayley-to-Belly** as **EVO1-066**.
  - 3★ Rare
  - Cost 5 / Damage 8
  - Strength 2
  - Grapple / Torso Trapped counter state
  - Grounds opponent
  - On Connect: search/draw Rose Plant; Rose Plant costs 4 less this Control sequence
  - Bayley-exclusive
- Bayley’s recommended deck remains exactly 60 pages and now carries three copies of each named signature instead of the shared Diving Elbow Drop and Belly-to-Belly Suplex.
- Bayley’s canonical signature list now includes Bayley-to-Belly, Bayley’s Diving Elbow and Rose Plant.
- Shared Diving Elbow Drop and Belly-to-Belly Suplex remain active for other Superstars. The generic Belly-to-Belly no longer carries obsolete Bayley-specific Rose Plant tutoring.

## Collector stability

No existing collector IDs were renumbered. The two new Evolution cards append at EVO1-065 and EVO1-066.

## Unchanged

No changes to Season XP, booster rarity, Superstar pity, duplicate conversion, foil treatment, HP, control rules, pin rules, or v0.12.70 presentation fixes.
