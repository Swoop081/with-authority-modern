# WWE Legacy v0.11.19 — Unified Card Art Studio

- Replaces the separate Move / Superstar creator workflow with one **Card Art Studio** linked from Profile.
- Studio contains all **372 active Season 1 collectibles**: 25 Superstars, 261 Moves, 25 Entrances, 27 Specials, 3 Managers, 21 Actions, 6 Supports and 4 Momentum cards.
- Filters by set, card type and search while preserving the real collector number.
- Superstar fronts: set logo + name only.
- Move fronts: set logo + Move name + compact COST / DAM only.
- Entrance / Special / Manager / Action / Support fronts: set logo + card name + small type label only.
- Momentum fronts: set logo + card name + compact Momentum identity.
- All other gameplay text stays on the shared card back.
- Exports direct-file-safe WebP files into predictable per-type custom-art folders with no manifest edit.
- Finished WebPs are now supported as canonical fronts for every active non-Superstar card type with automatic legacy-art fallback.
- The old Superstar Art Studio URL redirects into the unified studio.
